# AnalyticsViaPython

* Предобработка данных <br>
* EDA <br>
* Расчет метрик: средняя выручка на клиента, MAU, стики-фактор<br>
* Определение цикличности<br>
* Создание профилей клиентов<br>
* RFM-сегментация<br>
* Выдвинуты две стат. гипотезы, проведены стат. тесты<br>
